Project Name

Blue BioMass Mapping with IPCC SCC 

This project is based on the paper Holbach, Andreas, et al. "A spatial model for nutrient mitigation potential of blue mussel farms in the western Baltic Sea." Science of the Total Environment 736 (2020) 10.1016/j.scitotenv.2020.139624 and its respective app https://au-bios-model.shinyapps.io/MYTIGATE/

This repository is developed for Computation in Architecture masters program at the Royal Danish Academy. The project extends Holbach et al. Mytigate by integrating the future Shared Socioeconomic Pathways modeled by the IPCC CIMP6 model. It also allows to draw custom mussel farms, and export the resulting data to CAD software for further low-scale development.

The data used in the project is sourced from Copernicus Marine services, The Climate Data Store and Earth System Grid Federation. Data is not uploaded to this repository due to storage limitations but available upon request.
